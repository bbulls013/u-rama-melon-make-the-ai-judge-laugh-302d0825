Entry for the make.fun bounty
[Make the AI Judge Laugh](https://make.fun/bounty/u-rama-melon-make-the-ai-judge-laugh-302d0825):
one line about office life, under 200 characters, judged head to head
by a model picking the bigger laugh.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

Writes the joke to `entry.txt` in the output directory. The text is
fixed, so two runs write identical bytes.
